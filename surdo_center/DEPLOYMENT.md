# Перенос системы «ЮНА» на другой ноутбук

## Что установить на новом ноутбуке

1. **Python 3.12 x64** с [python.org](https://www.python.org/downloads/) — при установке включить `Add Python to PATH` и Python Launcher.
2. **PostgreSQL 17 или 18 x64** — запомнить пароль пользователя `postgres`, не отключать Command Line Tools и убедиться, что служба PostgreSQL запущена.

Node.js, Docker и отдельный веб-сервер для учебного локального запуска не требуются.

## Перенос вместе с пользователями и медицинскими данными

1. На старом компьютере закройте приложение и запустите `prepare_transfer.bat`.
2. Дождитесь сообщения о создании папки `.transfer`.
3. Скопируйте **всю папку проекта**, включая `.transfer`, на новый ноутбук. Папку `.venv` можно не копировать.
4. На новом ноутбуке запустите `deploy_new_laptop.bat`.
5. Когда скрипт попросит пароль администратора PostgreSQL, введите пароль пользователя `postgres`, заданный при установке PostgreSQL.
6. На вопрос о восстановлении резервной копии введите `ДА`.

Скрипт создаст новое виртуальное окружение, установит зависимости, подготовит роль и базу PostgreSQL, применит миграции, восстановит данные, проверит проект и откроет его в браузере.

## Чистая установка без старых данных

Скопируйте проект без `.transfer` и запустите `deploy_new_laptop.bat`. Будет создана пустая база со справочником услуг. Учётную запись администратора затем можно создать командой:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

## Важно

- Специализированные формы приёмов переносятся тем же способом: их версии, настройки услуг и данные входят в резервную копию PostgreSQL. После обновления проекта заново запустите `prepare_transfer.bat`, чтобы копия была актуальной. Скрипт развёртывания автоматически применит новые миграции.

- GitHub не хранит `.env`, `.transfer`, `.local-backups` и базу данных — они специально исключены из репозитория.
- Простого клонирования с GitHub достаточно только для кода. Для переноса существующих пользователей, паролей, пациентов и записей нужна резервная копия из `prepare_transfer.bat`.
- Не отправляйте папку `.transfer` посторонним: резервная копия содержит данные системы, а файл настроек — локальные пароли.
- Для последующих запусков используйте `start_surdo_center.bat`.
